# `src/engine/structural` — structural engines

One line per export of every file in `src/engine/structural`. SI units throughout (m, kg, s, N, N·m, Pa, J, W, rad);
arguments ending in `C` are in °C, `Deg` in degrees, `Rpm` in rev/min, `Hz` in hertz, `MmS` in mm/s. Functions take one
options object unless the signature shows positional arguments, and return plain objects with named fields; `[..]`
or a default value marks an optional argument. The JSDoc of each function lists every argument and returned field with
its unit, the reference and the validity range — the table gives the signature, the returned fields and the basis.
Invalid input throws `RangeError`.

Conventions shared by the frame engines: global Z up, node dofs ux, uy, uz, rx, ry, rz; member local x from end A to
end B, section axes y (strong) and z (weak); member axial force N > 0 is tension. Section-level checks state their own
sign conventions (compression-positive in `concrete.js`, compressive stresses entered as positive numbers in the plate
buckling functions).

## framebuckling.js — geometric stiffness, linear buckling, P–Δ

| export | signature → result (units) | computes / reference |

| `bucklingAnalysis` | `(model, { loadCase, nModes = 3, shearDeformation = true, consistentShear = true, tol = 1e-9, resTol = 1e-7, maxIter = 200 } = {})` → { factors, modes, residuals, axial, effectiveLengths, converged, iterations, shift, shifts, sturmCheck, system, reference } — buckling load factors [-] ascending, modes over all dofs (max component 1), residuals ρ = ‖Kφ − λ(−Kg)φ‖/‖Kφ‖ in the K⁻¹ norm [-], member axial forces [N], effective lengths [m] for buckling in the local x–z plane (about y: Ley, Ky) and x–y plane (Lez, Kz); sturmCheck false = the inertia count shows a skipped factor | Linear (eigenvalue) buckling of a frame: (K + λ Kg(N_ref)) φ = 0 with the member axial forces of a reference load case from a first-order analysis. Modes are accepted in ascending order on the change of λ (tol) and the residual (resTol), locked, deflated (K-orthogonal iteration vectors) and the shift moved up when the remaining ones lie beyond 2σ; groups of equal factors (identical members) are returned in full up to nModes. A final inertia count checks that no factor was skipped. Mesh behaviour: with the default consistent geometric stiffness the factors are upper bounds and fall monotonically when every element is halved (error ∝ h⁴ without shear flexibility, plus (Pcr/(G As))·O(h²) with it); one element per member cannot represent a member mode, and a member held at both ends needs four or more. consistentShear false restores the Hermite matrix on shear-flexible elements (fourth order, not a bound, not monotone, limit low by about 0.2 (Pcr/(G As))²). |
